# 🏨 Hotel Sales Analysis Dashboard

## 📌 Project Overview
This project presents an interactive **Hotel Sales Analysis Dashboard** built in **Microsoft Excel** using Pivot Tables, Pivot Charts, KPIs, and Slicers. The dashboard helps analyze hotel booking performance, revenue trends, customer behavior, and cancellation patterns.

The dataset contains over **119,000 hotel booking records** from both **City Hotels** and **Resort Hotels**, providing insights into revenue generation, booking status, customer types, and distribution channels.

---

## 🎯 Objectives

- Analyze hotel booking performance.
- Track revenue and revenue loss trends.
- Monitor booking cancellations and no-shows.
- Understand customer booking behavior.
- Compare City Hotels and Resort Hotels.
- Create an interactive dashboard for business decision-making.

## 🗂 Dataset Information

### Main Dataset Sheet
**Hotel Sales**

Key Columns:

| Column Name | Description |
|------------|-------------|
| Booking ID | Unique booking identifier |
| Hotel | City or Resort Hotel |
| Booking Date | Date of booking |
| Arrival Date | Guest arrival date |
| Lead Time | Days between booking and arrival |
| Nights | Length of stay |
| Guests | Number of guests |
| Distribution Channel | Booking source |
| Customer Type | Type of customer |
| Country | Customer country |
| Deposit Type | Deposit category |
| Avg Daily Rate | Average room rate |
| Status | Check-Out, Canceled, No-Show |
| Status Update | Last status update date |
| Revenue | Revenue generated |
| Revenue Loss | Revenue lost due to cancellations |

# 📊 Superstore Sales Analysis Dashboard

## Overview

This project analyzes Superstore sales data using Microsoft Excel. The objective was to clean the dataset, perform data analysis, create Pivot Tables, and build an interactive dashboard to identify sales and profit trends across product categories.

---

## Project Objectives

- Clean and validate the dataset
- Identify missing values and duplicates
- Analyze sales and profit performance
- Create Pivot Tables for business insights
- Build an interactive dashboard for reporting
- Present findings through visualizations

---

## Dataset

The dataset contains retail sales transactions including:

- Order ID
- Order Date
- Customer Details
- Product Information
- Category
- Sales
- Quantity
- Discount
- Profit
- Region

---

## Data Cleaning

The following cleaning steps were performed:

- Checked for missing values
- Checked for duplicate records
- Standardized text formatting
- Verified date formats
- Validated numerical fields
- Ensured data consistency

---

## Analysis Performed

### Sales Analysis
- Average sales by category
- Category performance comparison
- Sales trend analysis

### Profit Analysis
- Average profit by category
- Profitability comparison
- High-performing product categories

### Dashboard KPIs
- Total Sales
- Average Sales
- Total Profit
- Average Profit
- Category Performance Metrics

---

## Dashboard Features

- Interactive Pivot Charts
- Category-wise Sales Analysis
- Category-wise Profit Analysis
- Business Performance Insights
- Clean and user-friendly layout

---

## Key Insights

- Technology generated the highest average sales.
- Technology produced the highest average profit.
- Furniture generated strong sales but lower profitability.
- Office Supplies showed stable profitability across transactions.
- Sales and profit performance varied significantly by category.

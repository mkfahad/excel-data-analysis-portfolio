# Sales Performance Dashboard (Excel)

## Overview

This project analyzes sales performance data using Microsoft Excel. The dataset was cleaned, transformed, and visualized to identify trends in sales, profitability, products, customer segments, and country-level performance.
The project demonstrates the complete Excel analytics workflow from raw data preparation to dashboard creation.

## Project Workflow

### 1. Raw Data
The original dataset was stored in the **Sales Data Raw** worksheet.

### 2. Data Cleaning
The dataset was cleaned and standardized in the **Sales Data** worksheet.

### 3. Data Analysis
Pivot Tables were created to summarize and analyze key business metrics.

### 4. Dashboard Development
Interactive charts, KPIs, and visualizations were combined into a dashboard for business reporting.

## Data Cleaning Performed

The following cleaning steps were performed:

* Removed duplicate records
* Standardized text formatting
* Corrected inconsistencies in categorical fields
* Validated numerical values
* Ensured proper date formatting
* Verified sales and profit calculations

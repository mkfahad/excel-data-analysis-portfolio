# Coffee Sales Analysis Dashboard (Excel)

## Overview

This project analyzes coffee sales data using Microsoft Excel. The dataset contains order, customer, and product information and was transformed into an interactive dashboard to identify sales trends, customer behavior, product performance, and profitability.
The project demonstrates end-to-end Excel analytics skills, including data cleaning, data modeling, Pivot Tables, Pivot Charts, KPI creation, and dashboard development.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Lookup Functions
* IF Functions
* Conditional Formatting
* Dashboard Design

## Data Sources

### Orders Table

Contains:

* Order ID
* Order Date
* Customer ID
* Product ID
* Quantity
* Size
* Unit Price
* Sales

### Customers Table

Contains:

* Customer Information
* City
* Country
* Loyalty Card Status

### Products Table

Contains:

* Coffee Type
* Roast Type
* Product Size
* Unit Price
* Profit Information

## Data Cleaning & Preparation

The following cleaning and transformation steps were performed:

* Checked for missing and inconsistent values
* Standardized categorical values
* Validated customer and product identifiers
* Ensured proper date formatting
* Verified sales and profit calculations
* Combined data from Orders, Customers, and Products tables
* Created calculated fields for analysis

### Additional Calculated Columns

* Month Name
* Year
* Total Profit
* Profit Margin (%)

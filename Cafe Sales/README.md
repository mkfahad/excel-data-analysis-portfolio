# Cafe Sales Analysis Dashboard (Excel)

## Overview
This project analyzes café sales data using Microsoft Excel. The dataset was cleaned, transformed, and analyzed to identify sales patterns, customer purchasing trends, payment preferences, and product performance.
The project demonstrates an end-to-end Excel analytics workflow, including data cleaning, data validation, Pivot Tables, Pivot Charts, and dashboard creation.

## Project Workflow

### 1. Raw Data
The original dataset is stored in the **dirty_cafe_sales raw** worksheet.

### 2. Data Cleaning
Data cleaning and preprocessing were performed in the **cleaned_cafe_sales** worksheet.

### 3. Data Analysis
Pivot Tables were created to summarize key business metrics and trends.

### 4. Dashboard Development
Interactive charts and KPI visualizations were combined into a dashboard for reporting and decision-making.

## Data Cleaning Performed

The following data quality issues were addressed:
* Identified and handled missing values
* Replaced invalid entries
* Standardized product names
* Standardized payment methods
* Standardized location values
* Removed inconsistencies in categorical data
* Corrected formatting issues
* Validated numerical fields
* Prepared data for reporting and analysis

The cleaned dataset was stored separately to preserve the original raw data.
